# Perishable facts: UK advertising rules for copy

Checked 2026-10-06. Review every six months, or when the ASA or CMA announces a change.
Quotes are verbatim from the source pages.

| Rule | What it says | Source |
|---|---|---|
| CAP Code 3.1 | "Marketing communications must not materially mislead or be likely to do so." | https://www.asa.org.uk/type/non_broadcast/code_section/03.html |
| CAP Code 3.7 | "Before distributing or submitting a marketing communication for publication, marketers must hold documentary evidence to prove claims that consumers are likely to regard as objective and that are capable of objective substantiation." | same |
| CAP Code 3.18 | "Quoted prices must include non-optional taxes, duties, fees and charges that apply to all or most buyers. However, VAT-exclusive prices may be given if all those to whom the price claim is clearly addressed pay no VAT or can recover VAT." | same |
| CAP Code 3.23 | Do not call something "free", "gratis", "without charge" or similar if the consumer has to pay anything other than the unavoidable cost of responding and delivery. | same |
| CAP Code 3.33 | Comparisons with identifiable competitors "must compare products meeting the same needs or intended for the same purpose." | same |
| CAP Code 3.44 | "Marketing communications must not contain fake consumer reviews." A fake review "purports to be, but is not, based on a person's genuine experience." | same |
| CAP Code 3.45 | "Marketing communications must make clear where consumer reviews have been incentivised." | same |
| DMCCA 2024 Sch. 20 para 3 | Banned: "Displaying a trust mark, quality mark or equivalent without having obtained the necessary authorisation." | https://www.legislation.gov.uk/ukpga/2024/13/schedule/20 |
| DMCCA 2024 Sch. 20 para 13 | Banned: submitting or commissioning a fake consumer review; concealing that a review was incentivised; publishing consumer reviews or review information in a misleading way. In force since 6 April 2025. | same |

What this means for copy:

- "No.1", "best", "cheapest", "fastest", "most trusted", "5-star" are objective-sounding
  claims. Keep them only if the owner can produce the evidence (a ranking with its
  source, a price comparison on a stated date, the review platform's own figure).
- Quoting a review: copy the real text and name the platform. Do not edit the meaning,
  merge reviews, or present a selection as an average.
- A badge or logo (Which? Trusted Trader, Checkatrade, BAR, insurer) appears only if the
  owner confirms the membership is current.
- "Free quote" or "free survey" only when the customer pays nothing to get it; if any
  charge or deposit is attached, it is not free under CAP 3.23. Ask the owner.
